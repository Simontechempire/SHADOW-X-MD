# Public Assets

This directory contains all front-end assets for SHADOW-X-MD:

- **index.html** - Landing page
- **pair.html** - Device pairing page
- **dashboard.html** - Bot management dashboard
- **styles.css** - Main stylesheet
- **dashboard.css** - Dashboard-specific styles

## Usage

All HTML files are served by the Express server from this directory.

- Home: http://localhost:3000/
- Pairing: http://localhost:3000/pair
- Dashboard: http://localhost:3000/dashboard
